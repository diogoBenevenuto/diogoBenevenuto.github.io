# 🚀 Star Wars Space Shooter

Um jogo 2D do estilo space shooter inspirado no universo de Star Wars, desenvolvido como projeto acadêmico.

## 🎮 Sobre o Projeto

Este projeto consiste em um clássico **jogo de nave (space shooter)**, onde o jogador controla uma navee enfrenta inimigos em um ambiente inspirado em Star Wars.

Foi desenvolvido durante a faculdade com o objetivo de aplicar conceitos fundamentais de programação, lógica de jogos.

## 🛠️ Tecnologias Utilizadas

- JavaScript
- HTML5
- CSS3

## ⚙️ Funcionalidades

- Controle da nave pelo jogador
- Sistema de geração de inimigos
- Mecânica de disparo
- Detecção de colisão
- Sistema de pontuação
- Implementação de game loop

## 🧠 Aprendizados

Durante o desenvolvimento deste projeto, trabalhei com:

- Lógica de jogo e gerenciamento de estado
- Manipulação de eventos e entrada do usuário
- Técnicas de detecção de colisão
- Conceitos básicos de game design
- Estruturação de projetos com JavaScript, HTML e CSS
